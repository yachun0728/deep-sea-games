# TOP DOGGO 自動視角、輔助瞄準與操作教學試玩版

狀態：本機試玩，尚未部署。

- PASS：瀏覽器走完移動到圈、真實網球碰靶、換武器、翻滾四步；純鍵盤 W/J/Q/空白鍵與手機樣式下以滑鼠點 FIRE／換武器／DODGE 均實際操作。完成記憶後重新進入可直接開正式回合，暫停選單可以重練。
- PASS：FIRE 單次按住完成三次命中；教學步驟切換不禁止繼續射擊或移動；完成／跳過直接銜接正式回合。正式回合只在教學結束後建立；重練會結束原正式回合並重置第一關。
- PASS：自動化測試涵蓋前方瞄準、背後／側面／過遠／死亡敵人拒絕、牆面阻擋、角度跨正負 PI、教學結束記憶與開局邊界、實際練習球命中／打偏。
- PASS：三語字串測試、48 項 Python、既有 controls／exit／Worker SQLite 排行榜檢查及 Build。瀏覽器檢查時未見 runtime error。
