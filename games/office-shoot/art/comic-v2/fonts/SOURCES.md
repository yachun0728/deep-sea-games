# Local fonts

- Noto Sans TC variable: https://github.com/google/fonts/tree/main/ofl/notosanstc
- Bangers Regular: https://github.com/google/fonts/tree/main/ofl/bangers

Downloaded from the official Google Fonts repository on 2026-11-28. Noto Sans TC instantiated at weight 900 and subset to this game's Chinese UI plus ASCII; Bangers subset to ASCII. FontTools was used for WOFF2 conversion. Original OFL notices are included. All fonts are self-hosted; game runtime makes no Google Fonts request.
