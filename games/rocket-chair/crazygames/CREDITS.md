## In-game ambience
The office soundscape played during gameplay (room tone, muffled voices, typing, phones, printer, clock) is original and
synthesized live in the browser with the Web Audio API by the game's own code (`music.js`). No audio files are used for it.

## Sound effects
All sound effects are synthesized live with the Web Audio API by the game's own code. No audio files are used.

## Art
Characters, backgrounds and UI art were created for this game with AI image generation and edited for the game.

## Fonts
The game uses the player's system fonts. No font files are bundled.
