## 還原與響應式

原圖遊玩區為 490×641，實作使用 400×523 等比舞台。手機完整顯示原構圖，剩餘高度留深色邊；不裁切背景，不為填滿螢幕拉長人物或機器。數字、語言與開始／結算狀態為動態內容。死神手臂與鐮刀使用原畫圖層繞肩關節揮動；靈魂由輸送帶帶動，不以浮動替代角色走路。通行證與徽章同時依原判定淡出。

v2 依使用者截圖修正：動作文字獨立為 `rp-action-label`，固定在原黑色按鈕下半部中央，不再讓匿名 flex 文字偏移到鐮刀圖示旁。繁中／英／簡中中心位置相同。高班次提示移到下方留白；結算分享與排行榜重試固定在舞台內。

全部生成使用內建 image_gen，沒有啟用收費 API fallback。未採用另一張直式延展試稿。提示詞與來源見 `prompts.md`；實測記錄見 `QA.md`。

## 動作與操作修正版 v3

依使用者後續截圖修正 HUD、站位、揮擊、手套與幽靈移動。死神的下半身由整段輸送帶遮住，站在盒子後方；只有獨立的完整手套搭在桌緣。鐮刀從右上向下掃到金色判定區內的幽靈。手套與幽靈身體／鞋子以核准素材作參照重新分離，原檔及抽取證據保存在 `motion-v3/`，正式 WebP 在 `../art/motion-v3/`。

幽靈使用兩段腿骨、交替落腳／抬腳與彎膝，沒有以整張圖漂浮充當走路；減少動態效果模式仍保留必要的腿部動作。收魂後縮身落進盒中，不再浮過死神的臉。`ghost-walk-realtime.gif` 是實際瀏覽器原速影格，`downward-swing-3x-slow.gif` 是實際 0.28 秒揮擊的三倍慢放。

箭頭與愛心按紙牌位置對齊，文字按字體實際墨跡邊界置中。遊戲區禁止選字、拖曳、觸控／觸控板誤縮放；不影響遊戲外頁面。新增的原圖與提示詞見 `motion-v3/SOURCES.md`。
