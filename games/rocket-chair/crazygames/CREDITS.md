# Roar Through the Ceiling! — Credits

## Music
Both music tracks ("Nine-to-Five Shuffle" on the title screen and "Overtime Escape" in game) are original compositions
written for this game. They are synthesized live in the browser with the Web Audio API by the game's own code (`music.js`):
no audio files, samples, loops or third-party music are used.

## Sound effects
All sound effects are synthesized live with the Web Audio API by the game's own code. No audio files are used.

## Art
Characters, backgrounds and UI art were created for this game with AI image generation and edited for the game.

## Fonts
The game uses the player's system fonts. No font files are bundled.
