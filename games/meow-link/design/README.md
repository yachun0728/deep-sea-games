# Meow Link 手繪素材 v1

使用者於 2026-11-28 確認 `art-direction-v1.png` 的奶油色手繪貼紙風，要求製作正式版並置於大廳第 4 款。畫風、12 貓咪及物品會進入配對的設計已獲確認；最終成品試玩與封面仍待確認，未發布。

`source/` 保留每種圖案的生成原圖；`art/`（上一層）是保留 alpha 的 256px WebP 遊戲圖。`tiles.json` 是配對 ID、類別、名稱與素材檔對照，不以顏色判定配對。以不同姿態、輪廓與主色區分貓咪，拉布特徵為灰褐虎斑、額頭橘紋、黃綠大眼。

生成方式：內建圖片生成工具，每個獨立圖案分別生成，以核准設定圖作風格參考；每次明確要求單一物件、透明 alpha、完整輪廓、無 UI／文字／背景。原始提示與來源路徑另記 asset-generation.json。縮放與 WebP 壓縮只為遊戲下載與解碼需求，不取代原稿。

獨立規則池：簡單 6 貓咪＋三類各 2 物品，普通 12 貓咪＋三類各 4 物品，困難全 36。大廳封面 1056×1000、不透明，榜單縮圖 192×192，均另存原稿。原版檔案複製前雜湊在 ocean-link-source-hashes.json。
