## 直式版實作摘要

- 畫布 450×800。原 800×450 第一人稱場景保留為「場景座標」，用 `cam()` 以 800/450 的倍率置中裁切成直式（可見寬度約 253 場景單位）；背景、躲藏處、鬼、道具都在此座標內繪製，鬼與躲藏處的左右偏移以 `SIDE`／`KS` 縮小後才落在畫面內。
- HUD、教學、開場、結算、營火、圖鑑都在畫布座標（450×800）直排；道具欄在畫面下方。
- 手機全螢幕：左上退出、右上選單鈕，選單開啟後面板（設定、圖鑑、分享、體感）以底部面板顯示。移除橫向全螢幕與旋轉模式。
- 玩法、關卡、規則、追蹤與儲存不變。
