- 方向：日系手作、奶油色木紋桌面、黃紙纖維、霧白黏膠、陶土與鼠尾草配色。
- 角色：原創坐姿閉眼貓；頭、雙耳、口鼻、身體、胸毛、雙爪、尾巴可分開撕紙，搭配星星與月亮。

- 本次為 Preview 試玩稿，尚未取得正式角色／場景美術採納確認，不作正式大廳封面。
