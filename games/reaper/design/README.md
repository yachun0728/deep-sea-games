## 還原與響應式

原圖遊玩區為 490×641，實作使用 400×523 等比舞台。手機完整顯示原構圖，剩餘高度留深色邊；不裁切背景，不為填滿螢幕拉長人物或機器。數字、語言與開始／結算狀態為動態內容。死神手臂與鐮刀使用原畫圖層繞肩關節揮動；靈魂由輸送帶帶動，不以浮動替代角色走路。通行證與徽章同時依原判定淡出。
