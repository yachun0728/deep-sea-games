## 畫風方向

- 可愛貼圖風 2D 卡通：粗圓深棕勾線、平塗粉彩、極少陰影、奶油色底、Q 版比例，以小特效（塵土、星星、汗滴）表現動作。
- 遊戲內水果只有紅、橘、綠三色（蘋果、橘子、青蘋果）。攤位與籃子裡的葡萄、香蕉只是裝飾。
- 遊戲中貓與老闆娘都以背面出現（往畫面上方跑）。
