Used unchanged, looped on the title and result screens.

## Sound effects
Impact, crash, thruster, punch, scratch, bell, tick, click and confirmation sounds from Kenney's "Impact Sounds",
"Interface Sounds" and "Sci-Fi Sounds" packs (www.kenney.nl), Creative Commons Zero (CC0):
http://creativecommons.org/publicdomain/zero/1.0/ — converted to AAC (.m4a); the thruster sound is shortened in play.
The remaining effects are synthesized live with the Web Audio API by the game's own code.

## In-game ambience
The office soundscape played during gameplay (room tone, muffled voices, typing, phones, printer, wind) is original and
synthesized live in the browser with the Web Audio API by the game's own code (`music.js`). No audio files are used for it.

## Art
Characters, backgrounds, result-screen art, the desktop side background and UI art were created for this game with AI
image generation and edited for the game.

## Fonts
The game uses the player's system fonts. No font files are bundled.
