# TiCATiCA Cat Match — 貓貓三消 v0.6

未上架的手機／桌面試玩版，無倒數、無體力限制，可無限接關。

- 點選相鄰兩格或滑動交換；三連收集、四連產生直行／橫列消除、五連產生彩虹球、T/L 產生範圍消除。
- 金邊搭配紫色方向徽章表示整行／整列消除；橘色貓掌爆破徽章表示範圍消除；彩虹毛線球表示同色消除。
- 每關提示 3 次、洗牌 2 次；新關與重玩補滿，系統無解洗牌不扣次數。
- 只保存旅程進度，重新整理重玩目前關卡。獨立儲存 key：`proto-cat-match-save-v1`。
- 不接平台點數、GA4 或排行榜；「離開遊戲」返回正式站大廳。

發布前核對遠端基準 `617f730`，僅變更 `preview/`，保留其他遊戲與插隊圖片。本版只修正特殊棋子顯示，不修改消除判定、獎勵或存檔格式。

## v0.7 聲音（2026-11-23）

原創 Web Audio 循環小旋律（64 個八分音符約 18.6 秒，柔和正弦鐘音與低音和聲）及交換、無效交換、消除、連鎖升調、特殊消除、提示、洗牌、過關／失敗音效，沒有額外音檔下載。第一次點擊／按鍵才建立 AudioContext，重複操作維持單一排程。暫停與結算停止背景音樂，背景分頁與離頁靜音；恢復時以使用者操作啟動。

右上暫停選單可分別開關音樂／音效，使用 `proto-cat-match-audio-v1` 記住偏好。無 Web Audio 支援時停用開關，遊戲照常運作。不修改棋盤判定、道具次數或旅程存檔。

`node preview/cat-match/test-audio.mjs` 驗證手勢啟動、單一排程、獨立開關、儲存、暫停恢復、背景靜音、離頁清理與不支援降級。瀏覽器已確認 v0.7 開關操作、無音訊錯誤紀錄；音色與手機實際音量待使用者實機試聽。
