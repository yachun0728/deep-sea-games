# Berry Trail 來源

`berry-trail-v5.html` 為使用者於 2026-11-25 提供的原始遊戲，逐位元組保存，作為角色、森林場景與畫面設定參考。採用原始 Canvas 繪製，不重新生成角色素材。`play.html` 保留原畫面，補足站台契約與手機安全區。

`cover-render-v1.png` 為從遊戲原始 Canvas 繪圖產生的 1056×1000 滿版封面原稿，英文題字 Berry Trail。`cover.webp` 與 `leaderboard.webp` 分別為大廳封面及榜單縮圖。

`cover-imagegen-v2.png`：依使用者要求提升封面品質，使用內建 imagegen 生成，以遊戲 Canvas 圖為角色與色彩參考。採用大主角、莓果森林與兩行英文題字，提示詞見 `cover-imagegen-v2-prompt.txt`；目前大廳與排行榜使用此版，原 v1 保留。
