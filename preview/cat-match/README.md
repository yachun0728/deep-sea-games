# TiCATiCA Cat Match — 貓貓三消 v0.6

未上架的手機／桌面試玩版，無倒數、無體力限制，可無限接關。

- 點選相鄰兩格或滑動交換；三連收集、四連產生直行／橫列消除、五連產生彩虹球、T/L 產生範圍消除。
- 金邊搭配紫色方向徽章表示整行／整列消除；橘色貓掌爆破徽章表示範圍消除；彩虹毛線球表示同色消除。
- 每關提示 3 次、洗牌 2 次；新關與重玩補滿，系統無解洗牌不扣次數。
- 只保存旅程進度，重新整理重玩目前關卡。獨立儲存 key：`proto-cat-match-save-v1`。
- 不接平台點數、GA4 或排行榜；「離開遊戲」返回正式站大廳。
