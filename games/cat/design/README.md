## 畫風方向

- 可愛 Q 版 2D 卡通：橘色虎斑貓繫紅領巾與鈴鐺，粗深色勾線、亮彩平塗。
- 遠景為白天的歐風城鎮（藍天、紫色城堡剪影）。注意：和大廳封面 `../cover.webp`（夜晚／黃昏藍紫城市）不同，正式定稿前要決定統一哪一邊。

## 已知問題（需設計師補圖）

- 原圖沒有透明通道，棋盤格是畫上去的；以程式從邊緣去除淺色棋盤，白色腳掌邊緣偶有缺角。
- 解析度不足：貓約 130 px 寬，手機高解析螢幕上偏軟。
- 側面奔跑只有兩個姿勢（`runA`、`runB`），不是完整循環。
- 屋頂缺可拼接的左／中／右段；遠景不是無縫拼接（以鏡像處理）。
- 未使用：圖示、按鈕、HUD、彈窗、商店、愛心、鑽石等（遊戲沒有這些機制；商店與鑽石不符本站政策）。
