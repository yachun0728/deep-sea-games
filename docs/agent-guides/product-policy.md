# 遊戲產品原則

## 全遊戲產品原則：不得有博弈元素

2026-11-17 使用者指定，適用所有既有、隱藏、重新上架及新增遊戲：

- 禁止下注、押注金額選擇、全押、賠率／返還倍率、領回／收手領回、提前兌現，以及以繼續冒險換取更高點數返還的機制。
- 不得只改名稱或隱藏文字，卻保留下注、倍率結算、輸贏返還或 cashout 的實質玩法。隨機探索可以存在，但不得與押注、返還或博弈式獎勵連動。
- 遊戲應以操作、推理、探索、分數、關卡與最佳紀錄為核心。可保留固定入場點數與既有回點制度；入場費不是本金，不得依投入金額計算獎勵或返還。技能／里程碑獎勵需另訂固定規則，不得包裝成賠率或領回；速度、傷害等非點數返還的數值倍數不在此限。
- 舊程式與規則文件中的下注、倍率、領回僅是待改造的現況紀錄，不構成新設計或重新上架的許可。隱藏遊戲完成玩法改造與驗證後才可重新顯示。
- 純文件任務只記錄政策、現況及待辦，不得宣稱程式已移除博弈元素，也不得順便改動遊戲、錢包、儲存資料或 GA4。後續程式改造依使用者授權逐款處理，保留資料相容性與單次扣點／入帳／追蹤防護。

- 使用者核准的每日免費挖礦可依免費次數隨機贈點（每天3次、每次5挖、最多30點）；不得收取入場費、售賣加挖或提供投入換取更高獎勵的選項。此例外僅限免費補給，不授權其他遊戲加入博弈機制。
