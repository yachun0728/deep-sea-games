# 貓貓三消 v0.1（未上架）

使用者希望貓咪三消可以一直玩。本版以無上限的旅程關數、三種輪替棋盤、六種輪替收集目標形成可持續循環；不是已製作無限個獨立手工關卡。

- 每關 24 步，無倒數。合法三消才扣一步，連鎖自動補落；每關收集目標從 18 遞增至 30 後封頂。
- 四連產生列／行消除、五連產生彩虹球、T/L 產生 3×3 消除；特殊圖案可連鎖觸發，兩個特殊圖案交換也可啟動。
- 彩虹球與普通圖案交換清同類；兩個彩虹球交換清全盤。
- 無解自動洗牌；提示、主動洗牌、失敗重試不限次數，不耗步數。屬於輕鬆試玩平衡，尚未完成關卡通關率評估。
- `proto-cat-match-save-v1` 只保存目前旅程與最高旅程；重新整理重玩當前關，不保存中途棋盤。
- 手機點兩格或滑動，桌面滑鼠點選／拖曳。未加入平台錢包、GA4、排行榜、障礙物、音效、多語系與大廳入口。

## v0.2 操作與動畫修正（2026-11-23）

- 原版以瞬間換位及固定等待模擬交換／掉落，手感不連續。本版改用 requestAnimationFrame：交換 125ms、消除縮小淡出 115ms、重力補落 190ms，連鎖直接銜接；無效交換使用同一過場滑回。
- 滑動超過 0.22 格立即交換，不再等到放開；每個手勢只交換一次，按下時即顯示選取回饋。保留結算期間的操作鎖定，避免改壞棋盤。
- 剩餘步數於交換成功時立即更新；支援系統減少動態效果偏好，過場不影響判定與存檔。
- 驗證：引擎 1,350 次交換模擬通過；新增虛擬動畫時鐘驗證逐幀路徑、偏移清理、pointermove 立即交換，以及 pointerup 不重複扣步。骨架檢查與 5 項骨架工具測試、diff 空白檢查通過。
- 本機瀏覽器已刷新確認 v0.2，實際拖曳合法交換，收集小魚 18→15、步數 24→23、分數 0→30；截圖 `design/playtest-motion-v02.jpg`。尚未以手機實機量測幀率或驗證觸控手感；本次未推送。
