# CrazyGames 品質檢查

來源：[官方 Quality guidelines](https://docs.crazygames.com/requirements/quality/)，2026-11-23 核對。

## 規範層級

此頁標示為 **Guideline**，是品質建議，需搭配強制要求使用。不可把整頁寫成官方硬性通過門檻；若某項也出現在 Gameplay／廣告等強制規範，仍依該規範驗收。例如 Full 最多一次點擊進入玩法、英文支援、全螢幕按鈕限制，並非因本頁標示 Guideline 就變成選配。

## 官方建議摘要

- **引導**：直接在遊玩中教核心操作，可略過；圖像優先、少文字，按鈕清楚，不用尺寸或延遲誘導行為。
- **玩法**：目標明確、容易理解、操作一致、反應快；節奏／難度適當，避免無趣重複；若兼有單人與好友模式，入口同樣明顯。
- **辨識度**：名稱／圖示能區別他作，尊重 IP；便於擴充及維護，送審後不任意改主要類型。
- **視聽**：解析度與畫風一致、無壓縮瑕疵，音量舒適；名稱與宣傳符合實際類型與體驗。
- **鍵盤**：考慮 AZERTY／ZQSD；避免依賴 Escape 或 Ctrl／Cmd＋W 等瀏覽器保留操作，不要求玩家更改系統設定。

## TiCATiCA 實測紀錄方式（內部流程）

每款遊戲以實際版本、裝置與證據記錄：PASS／ISSUE／NOT CHECKED／N/A，另標示「官方建議」或所引用的強制規範。未實測不預填通過，品質建議存在問題也不等於官方已退件。

| 檢查情境 | 要記錄的證據 |
| --- | --- |
| 全新玩家首次開啟 | 到第一次可操作的時間／點擊數、是否理解當前目標；不將內部觀測時間當官方秒數門檻 |
| 教學與操作 | 是否能略過、提示是否擋住遊戲、滑鼠／觸控／鍵盤是否一致 |
| 核心循環 | 一次主要任務的操作回饋、等待／往返、失敗與重試的理解程度 |
| 裝置視聽 | 小尺寸文字、圖集清晰度、風格、音量及背景恢復 |
| 名稱與媒體 | 能否對應實際玩法，有無借用名稱／圖示或未實作功能 |
| 鍵盤相容 | 方向鍵／可替代配置、焦點、瀏覽器保留鍵是否誤觸 |

## Frontier Islands 待查例子

目前只規劃檢查，未進行 CrazyGames 品質試玩：觀察開場長文字是否妨礙理解；採集／建造的首次回饋是否清楚；移動、往返與等待是否過量；手機 HUD／搖桿是否互擋；鍵盤配置是否適合替代布局。記錄結果後再依使用者授權修改，不因整理指南直接改玩法、數值或教學。

報告放在 `output/publishing/crazygames/<game-slug>/quality-qa.md`，不放進遊戲 ZIP；不以自動測試代替真人體驗與視聽檢查。
