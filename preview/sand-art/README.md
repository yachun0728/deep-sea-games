# Sand & Chill｜沙沙時光 Demo

獨立 `preview/sand-art/`，Internal Preview；不接正式 Lobby、錢包、排行榜、Analytics、帳號、廣告或付款。無時間限制、分數或指定配色。直接開啟即能撕紙、倒沙與欣賞／換紙；Demo 沒有存檔，重整會清除作品。

## 實作

- 1 張原創貓咪（31 個獨立區塊，含輪廓、眼睛、鼻子、嘴巴與鬍鬚紙條）、12 色可複選；繁中／英文即時切換。
- 單檔 HTML，Canvas 原生繪圖，無外部字型、素材、套件或網路依賴。黃紙纖維、白色黏膠與貓咪皆為程式繪製的試玩稿，尚未作正式美術確認。
- 120 Hz 固定物理步進；俯視顆粒近似，包含高度／落下速度軸，以球粒接觸、慣性、動／靜摩擦、壓力傳遞形成堆積。新沙落下，上層鬆沙具有較低的阻力與切向耗損，比底層更容易滑下；工具與搖動可抬升鬆沙；只有接觸底面的顆粒可黏附。固定沙嵌入薄黏膠層，不再參與球粒碰撞，鬆沙可滑過已黏圖案。不是工業級粒體模擬。保留個別顏色與不規則顆粒邊緣。
- 逐粒檢查黏膠區域與接觸時間，達到停留條件後逐步黏附；已黏沙粒固定，黃紙不黏。沒有區塊填滿、混合成單色或自動清沙。
- 使用幾何路徑建立區塊 ID，避免抗鋸齒像素混出其他區塊 ID；黏附檢查顆粒接觸範圍，不把未撕開的輪廓當白膠。
- 細化為 0.7 邏輯像素的黏附位點；固定沙層以細位點保留覆蓋資訊，讓後續實際經過的沙能補入白膠空隙，仍不自動填區。鬆沙同時最多 5,000 粒，已黏沙不佔這個額度；鬆沙滿額只暫停新增，不刪舊沙。整張畫另有 260,000 粒的記憶體保護上限，高於畫板有效黏附位點數。餘沙持續移動至畫板外接沙區，再離開可視邊界才釋放記憶體。換紙是玩家明確重設。
- 刮板、牙籤、毛刷給鬆沙連續掃掠推力；沙匙少量倒沙，牙籤點擊可撕紙。工具不停止物理與重力。
- 手機由按鈕同時觸發 orientation／motion 權限（支援要求權限的瀏覽器）；感測無資料、拒絕或不支援時保留方向鈕。動態加速度峰值辨識搖動與短促敲擊，**仍需實機調校**，無法保證所有裝置分辨敲邊框與其他震動。手動方向鈕會停用感測，避免輸入互搶。
- 桌面滑鼠與方向鍵；空白鍵搖動、T 敲擊（畫板有焦點時），方向鈕按住傾斜、放開放平。可點畫框或敲擊按鈕替代實體敲擊。
- 程式合成 Web Audio ASMR：撕紙、連續倒沙、工具摩擦、敲擊；可靜音。初次手勢後才建立音訊，背景暫停聲音、釋放指標，前景繼續。不佔用 Escape 或 Ctrl/Cmd+W。

## 驗證

`node tools/test_sand_art.mjs` 執行 HTML 內實際物理引擎的確定性測試。`canvas.dataset.stats`／`peeled`／`fps` 為只讀驗收資訊；`window.sandArt` 為只讀快照介面，不供正式平台整合。

`tools/test_sand_art_browser.html` 為本機瀏覽器回歸頁，使用真實貓咪 Path2D 比對全部區塊、重現舊輪廓誤黏並量測耳朵覆蓋率。

見 [QA.md](QA.md)。正式版 30 圖、36 色、本機作品集、自動儲存及匯出皆未納入本次 Demo。


## Demo 03 操作

- 防止遊戲區文字選取、長按 callout、拖曳與 context menu；Canvas 使用非被動 touch 事件阻止瀏覽器預設手勢，遊戲雙指手勢由 pointer 處理。
- 1～4 倍畫板縮放：雙指縮放／平移、+／−／還原、桌面滾輪以游標為中心縮放。只改視角，世界座標、沙粒、黏附與重力不重設；雙指操作不會順便撕紙。
- 31 區：12 塊圖案紙、11 條可見輪廓紙條、雙眼、鼻子、嘴巴與 4 根鬍鬚。被其他形狀遮住的輪廓不外露。線條近點輔助依縮放縮小，放大後仍能精確選區。
- 「鎖定直式」在支援時透過使用者操作請求 fullscreen + orientation lock。瀏覽器拒絕或不支援時提示使用手機系統直式鎖定，不宣稱強制鎖定成功。手機橫放時保留並暫停作品、清除操作指標與暫停聲音，直放後原地恢復；桌面不套用手機橫放限制。
- `tools/test_sand_art_input.html` 使用 synthetic PointerEvent、mock pointer capture 和 mock 旋轉／鎖定 API 做輸入回歸。這些結果不代表真機觸控、iOS callout 或原生旋轉鎖定已通過。

## Demo 04 流沙調校

降低底面靜態阻力、速度拖曳及碰撞切向耗損，每對鬆粒於每輪只解一次碰撞；小角度傾斜較容易帶動沙堆，放平後仍漸停。已黏沙固定、紙張不吸沙與出界守恆不變。10° 流動回歸使用引擎模擬，實際手機手感另驗。

Demo 04 同時提高一般倒沙率（520 → 850 粒／秒，約 +63%），沙匙為 90 粒／秒。鬆沙陣列與已黏顆粒保留分開，碰撞只掃描鬆沙；已黏顆粒在綁定時畫入快取薄層，放大／還原不會重設或移動它們。換紙時快取與資料一起重設。

刮板以整條刀口掃掠碰撞推動鬆沙，毛刷以柔性寬刷痕帶動沙粒；工具不額外增加向上速度，也不把整堆沙收束到指標中心。工具接觸期間降低黏附速率，讓玩家能先推開表層鬆沙；已黏粒子固定不動。

## Demo 05 手感微調

保留低靜態阻力，增加底面速度阻尼及高速額外阻力；工具放開後較快減速。上層阻力仍低於底面，寬刀口／柔性毛刷、已黏沙容量與 850 粒／秒倒沙維持。回歸測試以起滑距離及放開後的停止距離雙向限制，避免再次在「黏滯」和「過滑」之間跳動。

感測以啟用時手持角度作為放平基準；先拿穩再啟用，關閉後重開即可再校正。白膠對接觸中的沙粒有額外阻力與較快黏附；工具主要以刀口／刷毛接觸推動，不靠放開後的長距離慣性。

## Demo 07 沙堆與白膠

原地長按可在已支撐的鬆沙上方續倒，下層承重、高層屈服滑落，刮板與毛刷可攤開鬆沙。裸膠加快逐粒捕捉；固定顆粒按覆蓋足跡封住黏附位點，避免已上色位置被後色反覆黏進。仍不自動填滿區塊。

## Demo 08

The five tools are the paper-lifting pick, pour, scraper, brush and spoon. Tap or drag the pick to lift paper. Twelve sand jars allow multiple selections or none. Motion, shake and tap stay on the desk; tilt arrows, portrait lock, audio and help are in Settings. Zoom controls sit below the board.
