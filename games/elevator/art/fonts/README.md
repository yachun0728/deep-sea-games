# Queue Cutter Rounded

遊戲專用的 Huninn 圓體子集，2026-11-28 用於統計標籤、數字、狀態與操作鈕。以本機 WOFF2 載入，約276 KB，不依賴第三方字體服務。標題維持核准的英文字樣。

來源：Google Fonts 的 [Huninn](https://github.com/google/fonts/tree/main/ofl/huninn)，原作者 [justfont](https://github.com/justfont/Huninn)。授權完整保存在 `OFL.txt`。

原始字檔：`https://raw.githubusercontent.com/google/fonts/main/ofl/huninn/Huninn-Regular.ttf`

下載來源 SHA-256：`1bd770a5ffc0c06723b567686f8b5db5abf9ab54227f3bbc4e6fd648f4698805`。

用 fontTools subset / Brotli 轉製，內部 family 與 PostScript 名稱已改為 Queue Cutter Rounded / QueueCutterRounded。保留原始授權及作者資訊。子集含本遊戲繁中、英文、動態文字與既有簡中轉換字元，更新文字時應同步檢查字元覆蓋；缺字保留系統中文字體 fallback。未在使用者系統安裝字體，製作工具僅安裝於 `/tmp/queue-cutter-font-build`。
