# 新增遊戲與訪客排行榜

## 新增遊戲時的檢查清單

新增遊戲必須先符合[全遊戲產品原則：不得有博弈元素](product-policy.md)。新增遊戲操作順序見 [README.md](../../README.md)。在使用者授權新增遊戲時，核對大廳卡片／圖示／分類、`view-*`、`VIEWS`／標題、共用餘額、單次扣款與單次結算、路由與輸入釋放、GA4 遊戲名稱和回合追蹤、必要的重設防護。同步更新架構與玩法文件。不得在純文件任務中執行這些程式變更。

## 新增遊戲預設包含訪客排行榜

- 使用者授權新增或上架遊戲時，將排行榜納入同次實作範圍，依 [README 的新增遊戲必接訪客排行榜](../../README.md#新增遊戲必接訪客排行榜) 主動完成前端、Worker 驗證與測試，於同一份 PR 提交。無競賽指標的免費補給須明列不參與原因。
- 每款由 Worker 依合法操作與對局狀態計算成績，驗證訪客所有權、版本、時間與結束點。共用規則放在 `shared/`，沿用既有訪客 API 和重送保護。
- 訪客只寫 `game_leaderboard`，每款 D1 留前 50 筆。`player_best_scores` 供登入帳戶使用。大廳每款只顯示最高分一筆，同分依伺服器紀錄時間與寫入順序，顯示最早達到的人。
- 上架前完成正常對局到 D1、API、大廳的核對，測試同分、低分、非法成績、重送、空榜、網路失敗和桌面／390px 中英文。PR 記錄已執行結果及未驗證事項。依 migration、Worker、前端順序發布，正式站再驗證。
- 純文件需求更新本規範與驗收要求；文件更新不代表既有遊戲已完成串接。
